# AnnaSetu — AI Food Waste Management & Redistribution Platform

> **Anna Setu** — *Anna* (food/grain) + *Setu* (bridge) → **"the bridge for food."**

AnnaSetu (अन्नसेतु) is an intelligent platform designed to predict food surplus, monitor real-time quality & cold chain integrity, match surplus food with nearby NGOs/food banks, and track ESG sustainability metrics for institutional kitchens and food processing units.

## Features

- **Surplus & Forecast**: Predictive analytics for meal preparation, production batch surplus, and inventory variance.
- **Quality & Safety Alerts**: Automated sensor monitoring for temperature, humidity, shelf life, and microbial risk.
- **Redistribution Hub**: Matching excess meals and raw ingredients with verified local NGOs, shelters, and food banks.
- **Sustainability & ESG Reporting**: Track total food rescued (kg), meals redirected, CO₂ emissions prevented, water saved, and export ESG compliance reports.
- **Multi-Unit Toggle**: Switch seamlessly between **Institutional Kitchen** (e.g., cafeterias, catering) and **Food Processing Unit** operating modes.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) / React 19
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com)
- **UI Components**: [Radix UI](https://www.radix-ui.com) & Lucide Icons
- **Charts & Visualizations**: [Recharts](https://recharts.org)
- **Build Tool**: [Vite](https://vitejs.dev)

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or bun

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

The application will be available at `http://localhost:8080/`.

### Building for Production

```bash
npm run build
```
